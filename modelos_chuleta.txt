================================================================================
  SUNNY — CHULETA DE MODELOS (mayo 2026)
================================================================================

Variables de entorno de Sunny:
  SUNNY_M1_PROVIDER / SUNNY_M1_MODEL   → Comprensión (m1)
  SUNNY_M2_PROVIDER / SUNNY_M2_MODEL   → Planificación (m2)
  SUNNY_M3_PROVIDER / SUNNY_M3_MODEL   → Agente visual GUI (m3)
  SUNNY_M4_PROVIDER / SUNNY_M4_MODEL   → OCR Summarizer (m4)
  GROQ_API_KEY                         → Activa Groq + capa de enriquecimiento
  CEREBRAS_API_KEY                     → Activa Cerebras

  Defaults actuales:
    m1 → ollama / qwen2.5:3b
    m2 → cerebras / llama3.1-8b
    m3 → cerebras / llama3.1-8b
    m4 → ollama / qwen2.5:3b

  ├──────────────────────────────────────────┼───────┼──────────────────────────┤
